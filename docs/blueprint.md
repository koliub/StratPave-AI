# **App Name**: Word Node

## Core Features:

- React Flow Canvas: The core of the app; a React Flow canvas with a single node.
- Input Prompt: Allow the user to write in a simple prompt into a single text input element.
- Summarization: AI that reduces the user provided prompt into a single word. The LLM will act as a summarization tool to condense the prompt to one word.
- Word Display: Displays the summarized word as the single text rendered in the React Flow Node

## Style Guidelines:

- Primary color: Neutral background with a slightly darker card color.
- Accent: Teal (#008080) for the React Flow node.
- Simple, full-screen layout with the input field at the top and the React Flow canvas taking up the remaining space.
- Minimal iconography, focusing on clear and simple interactions.
- Subtle animations for node updates and AI processing states.
